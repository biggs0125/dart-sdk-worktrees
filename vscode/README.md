# Dart SDK Worktree Follower (`nw`)

VS Code / Remote-SSH / Cursor / Jetski extension packaged with
[`dart-sdk-worktrees`](https://github.com/biggs0125/dart-sdk-worktrees). Keeps
your Dart SDK workspace (`active.code-workspace`) and open editor tabs synced in
place as you switch, create, or delete worktrees with `nw` and `ds`.
